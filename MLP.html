MLP 是怎么「学」出参数的

从 XOR 的 4 个样本出发，不调用任何深度学习框架，手写前向传播、二元交叉熵、反向传播与 Adam，把一个 2→2→1 多层感知机的 9 个参数从随机数训练到能分出非线性边界，再把每一步都画出来。

01

题目：为什么必须「学」参数

XOR（异或）只有 4 个样本，却是感知机最著名的反例：同一类的两个点处在对角线上，任何一条直线都分不开它们。

XOR 真值表

输入 x₁, x₂目标 y说明
[0, 0]0全 0 输出 0
[0, 1]1只有一个 1 输出 1
[1, 0]1只有一个 1 输出 1
[1, 1]0两个都是 1 反而输出 0
单层感知机只能给出 w₁x₁ + w₂x₂ + b > 0 这样的一条直线。把四类点代进去会得到互相矛盾的不等式，所以无解 —— 必须先用一个隐藏层把输入「变形」。

输入空间里的四个点

本次作业要完成三件事：① 手写实现参数学习（不用框架现成的优化器）；② 记录训练过程中 9 个参数与损失的变化；③ 可视化参数、分类边界与预测结果，并解释参数到底学到了什么。

02

网络结构与一次前向传播

两个输入、两个隐藏节点、一个输出，一共 9 个可学习参数：W₁(2×2)、b₁(2)、W₂(2)、b₂(1)。

结构示意

前向传播公式

z₁ = x₁w₁₁ + x₂w₂₁ + b₁ , h₁ = σ(z₁)
z₂ = x₁w₁₂ + x₂w₂₂ + b₂ , h₂ = σ(z₂)
z₃ = h₁v₁ + h₂v₂ + c , ŷ = σ(z₃)
σ(t) = 1 / (1 + e−t)

参数在代码里按 [w₁₁, w₁₂, w₂₁, w₂₂, b₁, b₂, v₁, v₂, c] 的顺序存成一个长度为 9 的数组；σ 是 Sigmoid，把任意实数压到 (0, 1) 当作概率。

参数组形状作用
W₁, b₁2×2, 2把输入投影到隐藏空间
W₂ (v), c2, 1在隐藏空间画一条分界线
03

实现：参数是怎么被改动的

「学习」就是反复做四件事：算出预测 → 量出差距 → 把差距按链式法则分摊给每个参数 → 沿梯度反方向修改参数。

1 · 前向计算代入当前 9 个参数，得到 4 个样本的 ŷ。h=σ(xW₁+b₁), ŷ=σ(hW₂+c)
2 · 计算损失二元交叉熵衡量预测与目标的距离。L=−mean[y·lnŷ+(1−y)·ln(1−ŷ)]
3 · 反向传播从输出误差 d₂=ŷ−y 出发，乘 Sigmoid 导数逐层回传。∂L/∂W = hiddenᵀ · d
4 · Adam 更新用梯度的一阶、二阶动量自适应地调整步长。θ ← θ − lr·m̂/(√v̂+ε)

核心代码（mlp_xor.py 节选）

def forward(p, x):
    z1 = x[0]*p[0] + x[1]*p[2] + p[4]
    z2 = x[0]*p[1] + x[1]*p[3] + p[5]
    h1, h2 = sigmoid(z1), sigmoid(z2)
    y_hat = sigmoid(h1*p[6] + h2*p[7] + p[8])
    return h1, h2, y_hat

def gradients(p):            # 手写反向传播
    g = [0.0]*9
    for i in range(N):
        x = X[i]
        h1, h2, y_hat = forward(p, x)
        d2 = y_hat - Y[i]                 # 输出层误差
        g[6] += d2*h1; g[7] += d2*h2; g[8] += d2
        d1a = d2*p[6]*h1*(1-h1)           # 误差经 W2 回传
        d1b = d2*p[7]*h2*(1-h2)
        g[0] += d1a*x[0]; g[1] += d1b*x[0]
        g[2] += d1a*x[1]; g[3] += d1b*x[1]
        g[4] += d1a;      g[5] += d1b
    return [v/N for v in g]             # 全批量平均

def train(epochs=1500, lr=0.05, seed=2):
    p = make_params(seed)               # 9 个参数初始化
    m, v = [0.0]*9, [0.0]*9             # Adam 动量
    for t in range(1, epochs+1):
        g = gradients(p)
        for j in range(9):
            m[j] = .9*m[j] + .1*g[j]
            v[j] = .999*v[j] + .001*g[j]*g[j]
            mh = m[j]/(1-.9**t); vh = v[j]/(1-.999**t)
            p[j] -= lr*mh/(math.sqrt(vh)+1e-8)
    return p

05

观察与结论

① 参数确实「学」到了东西。

初始 9 个参数接近 0 附近的小随机数，Loss 0.7105、准确率 50%；1500 轮后 Loss 0.000883、准确率 100%。隐藏层两个节点分别学成了「与非」和「或非」式的特征检测器：h₁ 只在 (1,1) 时接近 0，h₂ 只在 (0,0) 时接近 1，输出层用 v₁≈+14.5、v₂≈−14.8 把两者相减，于是 (0,1)、(1,0) 被判为 1，另外两点判为 0。

② Loss 曲线有一段「平台期」。

前约 100 轮 Loss 几乎停在 0.693（四个样本都猜 0.5），这是 Sigmoid 饱和导致的梯度很小；一旦走出平台，Loss 迅速下降到 0.02 以下，参数与决策边界在这个阶段同时发生明显变化。

③ 初始化很重要：不是每次都能学会。

点「试试会卡住的种子」（seed = 20261122）重新训练，会看到 Loss 停在约 0.3467、准确率只有 50%：网络掉进了局部极小，把两个样本永远预测成 0.5。这正是 XOR 小网络的经典现象，也说明「学习参数」不等于「一定学得出来」。

④ 可视化让「黑箱」变得可检查。

权重连线图能看出哪些连接被强化、符号是正是负；决策区域从一整片模糊的 0.5，逐渐分裂成两个对角区域；隐藏空间散点图则直接显示：非线性问题被变换成了线性可分问题。
